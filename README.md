# oop-wrapper-p5
In Python, OOP means Object-Oriented Programming. If you mean wrapper in OOP, a wrapper is something that surrounds another object, function, or value to provide additional functionality or make it easier to use.
 What is OOP?
Definition: Object-Oriented Programming (OOP) is a programming approach that organizes code using classes and objects.
#Class
*A class is a blueprint for creating objects.
Example: Car is a class.
# Object
*An object is an instance of a class.
Example: my_car is an object of the Car class.
# Encapsulation
*Encapsulation combines data and methods inside a class.
# Inheritance
*Inheritance allows one class to reuse features of another class.
2. What is a Wrapper Class?
Definition: A wrapper class is a class that contains another object and can add extra features or control how that object is used. 
*Real-life example: A mobile phone cover protects and surrounds a phone. Similarly, a wrapper class surrounds an object.
